# Dreamcraft (React Edition)

A Minecraft-inspired 3D voxel sandbox game built with React, Vite, TypeScript, Tailwind CSS, and Three.js.

## Features
- Procedural voxel terrain generation with grass, dirt, stone, ores, and trees
- First-person controls with pointer lock, jumping, sprinting, and fall damage
- Block breaking and placing with 3D handheld tool swing animation
- Crafting and Inventory screen
- Interactive Main Menu, World Select screen, Settings, and Marketplace
- HUD with health hearts and hotbar slot management
